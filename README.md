# Flutter E-Commerce Application

A full-featured cross-platform e-commerce mobile application built with Flutter, Firebase, Riverpod, and Hive. This project demonstrates production-ready implementation of modern Flutter development practices with real-time data synchronization, offline-first architecture, and clean state management.

## Features

- **User Authentication** - Secure sign-up, login, and logout with Firebase Auth
- **Product Catalog** - Real-time product listing with infinite scroll pagination
- **Shopping Cart** - Add, remove, and manage cart items with live updates
- **Offline Support** - Local data persistence with Hive for seamless offline experience
- **Theme Management** - Dark and light mode support with persistent user preferences
- **Responsive UI** - Adaptive design that works across all screen sizes
- **Profile Management** - User profile viewing and logout functionality

## Tech Stack

- **Framework:** Flutter & Dart
- **Backend:** Firebase Authentication & Cloud Firestore
- **State Management:** Riverpod
- **Local Storage:** Hive
- **Networking:** Dio & HTTP Client
- **UI Components:** Flutter Material Design
